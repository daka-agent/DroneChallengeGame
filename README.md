# 🚁 雾都飞升：无人机挑战

> 一款基于 Web 技术开发的跑酷类 H5 小游戏，无需安装，打开即玩。

[🌐 在线体验](https://daka-agent.github.io/DroneChallengeGame/) · [📥 下载 ZIP](https://github.com/daka-agent/DroneChallengeGame/archive/refs/heads/main.zip)

---

## 🎮 游戏说明

**雾都飞升** 是一款以赛博朋克都市为背景的无人机无尽跑酷游戏。

```
摁下空格键  →  开始游戏
← → 方向键  →  控制左右移动
```

无人机将 **自动持续跳跃**，玩家只需控制左右方向，引导无人机跳上越来越高的平台。随着高度增加，游戏速度会逐渐加快，并进入不同主题区域，直到无人机不慎坠落……

---

## ✨ 游戏特色

| 特性 | 说明 |
|------|------|
| 🕹️ **纯前端实现** | HTML + CSS + JavaScript，无任何外部依赖 |
| 🎨 **四大主题关卡** | 城市区 → 工业区 → 云层区 → 风暴区，每区独特配色与氛围 |
| ⚠️ **多种障碍物** | 尖刺（接触即死）、激光（周期开关）、风场（横向推力） |
| 🧊 **特殊平台** | 移动平台（水平滑动）、冰面平台（摩擦力低）、断裂平台（踩上后消失） |
| 🛡️ **护盾道具** | 拾取后获得 8 秒无敌保护 |
| 🔊 **程序化音效** | Web Audio API 合成，无需音频文件 |
| 📱 **移动端适配** | 支持触摸左右分屏控制 |
| 🏆 **无尽模式** | 实时记录当前高度与历史最高 |
| ⚡ **速度递增** | 游戏时间越长，速度越快，挑战性越高 |
| 🔄 **环绕穿墙** | 飞出屏幕边缘将从对侧出现 |

## 🗺️ 关卡区域

| 区域 | 触发高度 | 特色 |
|------|---------|------|
| 🔵 **城市区** | 0 m | 基础区域，赛博朋克建筑背景 |
| 🟠 **工业区** | 300 m | 橙色暖色调，出现移动平台与特殊平台 |
| 🟣 **云层区** | 700 m | 紫蓝夜空，尖刺、激光、风场障碍物登场 |
| 🔴 **风暴区** | 1200 m | 深红暗夜，闪电特效，全类型障碍物密集 |

## 🛠️ 本地运行

### 方法一：直接打开
下载后双击 `index.html`，用任意现代浏览器（Chrome / Edge / Firefox / Safari）打开即可。

### 方法二：本地服务器
```bash
# Python 3
python -m http.server 8080

# Node.js
npx serve .

# PHP
php -S localhost:8080
```
然后访问 `http://localhost:8080`

## 🎨 音效系统

游戏使用 **Web Audio API** 程序化合成所有音效，无需加载任何音频文件：

| 音效 | 触发时机 |
|------|---------|
| 🚀 起跳音 | 无人机每次弹跳（音调随速度变化） |
| 👣 落地音 | 踩上平台瞬间 |
| 🧊 冰面音 | 落在冰面平台时 |
| 💥 断裂音 | 断裂平台消失时 |
| 🛡️ 护盾音 | 拾取护盾道具时 |
| 🎉 里程碑音 | 每上升 50 米 / 进入新关卡区域 |
| 💀 坠落音 | 游戏结束时 |
| 🎶 启动音 | 游戏开始时 |

> 点击右上角 **🔊** 按钮可随时静音。
